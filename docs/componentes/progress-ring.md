# ProgressRing

Anillo de progreso con el porcentaje en el centro. Avanza con `dur-grow` y `ease-arrive`.

- **Props**: `value` (0–100), `size` (96), `thickness` (8), `tone` (`rams` · `klein` · `ink` · `verde`), `label`, `children` (sustituye al porcentaje).
- Para progreso continuo de una sola cosa (sesión, día). Para "n de m" contables, `DotGrid` o `StateMark`.
