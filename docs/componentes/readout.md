# Readout

El número que manda: cifra en `Doto` (puntos) con etiqueta mono encima y unidad pequeña. Temporizador, cuenta atrás, contador.

- **Props**: `value`, `unit`, `label`, `meta` (línea técnica debajo), `size` (`hero` 120 · `display` 64 · `label` 24), `live` (anuncia cambios a lectores de pantalla; solo para hitos, no cada segundo).
- Un `hero` por pantalla, arriba a la izquierda o centrado como cuenta atrás 3·2·1. Cifras tabulares: no bailan al cambiar.
