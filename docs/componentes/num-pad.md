# NumPad

Teclado numérico para importes: cifra enorme con la moneda pequeña, teclas planas pegadas como una calculadora, coma decimal (máx. 2 decimales) y borrar. También acepta el teclado físico.

- **Props**: `value`/`defaultValue` (string), `onChange(s)`, `currency` (`€`), `maxLength` (7), `hint`, `onSubmit(number)`, `submitLabel`, `keyboard` (escucha teclas), `label`.
