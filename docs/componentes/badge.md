# Badge

Contador o punto de aviso sobre otro elemento (un icono, una tecla, un avatar). Aparece escalando desde cero.

- **Props**: `count`, `max` (99, luego "99+"), `dot` (solo punto), `tone` (`rams`), `label` (qué cuenta, para lectores: "3 nuevos"), `children`.
- 0 no se muestra. Para estados de texto, `Chip`.
