# Steps

Progreso por pasos con el lenguaje de estados: disco = hecho, puntos = paso actual, aro = pendiente, unidos por un filete que se rellena. Para onboarding y procesos de 3–6 pasos.

- **Props**: `steps` (etiquetas), `current` (índice), `label`.
- Etiquetas de una o dos palabras. El paso actual lleva `aria-current="step"`.
