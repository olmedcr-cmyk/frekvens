# StateMark

El lenguaje de estados de la casa: **aro** = pendiente, **puntos** = en curso, **disco** = hecho. Tres formas, un mismo diámetro, sin color.

- **Props**: `state` (`empty` · `partial` · `full`), `size` (24), `label` (por defecto: Pendiente / En curso / Hecho), `children` (texto al lado).
- Úsalo en listas de tareas, calendario de entrenos, pasos de onboarding y reservas. El color puede acompañar, nunca sustituir a la forma.
