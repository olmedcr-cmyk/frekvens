# Keycap

Tecla mecánica esculpida, como las de un macropad: falda más oscura, superficie clara con brillo arriba y hundimiento de 2 px al pulsar. Ocupa varias celdas de rejilla con `w`/`h` (la tecla `+` de dos alturas, el `0` doble).

- **Props**: todas las de `button` + `tone` (`paper` · `ink` · `rams` · `sol` · `klein`), `w`, `h`, `sub` (segunda leyenda).
- Mínimo 56 × 56. Para acciones de interfaz, `KeyButton`: Keycap es para teclados y calculadoras.
