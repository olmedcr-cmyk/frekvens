# Grille

Rejilla de altavoz o lámpara en un disco o una cúpula: ranuras horizontales o agujeros de puntos recortados en un círculo de color. Es el retrato de un aparato: úsalo como arte de un Tile, una carta o una pantalla de audio.

- **Props**: `variant` (`slots` · `dots`), `shape` (`disc` · `dome`, la media esfera de una lámpara), `size` (160), `pitch` (paso de los puntos), `tone` (`verde` · `ink` · `sol` · `rams` · `tabaco` · `surface`), `label` (si comunica algo; si no, es decorativo).
- Una por vista. Con `dome`, apila una `Grille` o un disco debajo para la silueta completa de lámpara.
