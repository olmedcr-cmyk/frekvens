# Checkbox

Casilla cuadrada de 32 px con ✓ que se rellena de `ink`. Admite estado mixto (−). Toda la fila (casilla + texto) es pulsable: 44 px de alto como mínimo.

- **Props**: `label` (o `children`), `hint`, `checked`/`defaultChecked`, `onChange(bool)`, `indeterminate`, `disabled`.
- Para opciones independientes y para aceptar condiciones. Si el cambio surte efecto al instante, usa `Switch`.
