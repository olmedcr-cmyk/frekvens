# LineChart

Línea suave con marcador de **ahora**: lo pasado en trazo lleno, lo previsto fino y atenuado, y un aro con línea vertical en el punto actual (la curva del clima de las referencias).

- **Props**: `data` (números), `labels` (eje x), `now` (índice), `unit`, `tone` (`ink` · `rams` · `klein`), `width` (360), `height` (140), `caption`, `label`.
- El nombre accesible resume mínimo, máximo y valor actual. Una línea por gráfico; para comparar categorías, `BarMeter`.
