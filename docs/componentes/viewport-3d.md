# Viewport3D

Visor 3D sin dependencias (CSS 3D): un objeto sobre un suelo de puntos que se gira arrastrando, se acerca con la rueda y tiene vistas rápidas (Iso, Frente, Arriba), un gizmo de ejes y la lectura de ángulos en mono.

- **Props**: `shape` (`cube` · `stack`), `tone` (`rams`), `size` (120), `pitch`, `yaw`, `height` (320), `label`.
- **Teclado**: flechas giran, + y − acercan. Para modelos reales, usa este marco y su barra con un render WebGL dentro.
