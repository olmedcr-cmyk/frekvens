# EmptyState

Estado vacío: un aro de puntos, un título que dice qué falta, una frase que dice qué hacer y, si se puede, la acción.

- **Props**: `title`, `text`, `action` (`{label, onClick}`), `shape` (forma de `DotMatrix`, `ring`), `compact`.
- Nunca "No hay datos": "Aún no has entrenado esta semana" + "Reservar".
