# Clock

Reloj analógico de pared o de tarjeta: disco `ink` con agujas `paper` y segundero `rams` (variante `disc`), esfera de 60 puntos (`ticks`) o la hora en matriz de puntos (`dot`). Sin `time`, va en vivo.

- **Props**: `time` (`'10:09'` fija la hora), `variant` (`disc` · `ticks` · `dot`), `size` (200), `seconds` (true), `caption`.
- El lector de pantalla oye "Son las 10:09"; no anuncia cada segundo.
