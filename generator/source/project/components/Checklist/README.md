# Checklist

Lista de puesta en marcha: contador `n / total` con puntos, y cada paso desplegable con su explicación y su acción. Al marcar uno, se abre el siguiente pendiente.

- **Props**: `title`, `items` (`[{title, text, action, done, onAction}]`), `defaultOpen` (índice).
- Para onboarding de producto. 3–7 pasos; el primero, el más fácil.
