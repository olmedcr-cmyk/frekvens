# AreaChart

Área en semitono: la superficie bajo la curva se rellena con una trama de puntos del color de la serie (no con un degradado) y la línea va encima, suave. Admite varias series superpuestas con leyenda.

- **Props**: `series` (`[{label, data, tone}]`), `labels`, `width`, `height`, `zero` (eje desde 0), `legend`, `label`.
- El texto alternativo dice de dónde a dónde va cada serie. Máximo 3 series: más se lee peor.
