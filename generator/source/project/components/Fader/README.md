# Fader

Fader de mesa de mezclas: ranura `ink`, regla con 11 marcas y un capuchón de color que se arrastra en vertical. Lectura mono debajo. Para niveles de canal, macros de un teclado, luces.

- **Props**: `value`/`defaultValue`, `onChange(v)`, `min`, `max`, `step`, `height` (200), `tone` del capuchón, `format(v)`, `label`.
- Slider vertical (`aria-orientation`): ↑↓ paso a paso, RePág/AvPág de 10 en 10.
