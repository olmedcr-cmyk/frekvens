# DonutChart

Donut de segmentos redondeados y separados, con el total (o un dato) en puntos en el centro y la leyenda con porcentajes debajo.

- **Props**: `segments` (`[{label, value, tone}]`), `value` (centro), `caption`, `size` (200), `thickness` (22), `gap` (6°), `label`.
- 2–5 segmentos. Para una sola proporción, `ProgressRing`; para comparar, `SplitBar`.
