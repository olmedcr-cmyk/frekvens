# Heatmap

Actividad en semitono: una rejilla de puntos (semanas × días) donde el tamaño del punto es la cantidad. Sin escala de colores: el dato se lee por tamaño, como un periódico impreso.

- **Props**: `data` (valores por día, en orden), `rows` (7), `cell` (14 px), `tone` (`ink` · `rams` · `klein` · `verde`), `unit`, `caption`, `label`.
- El nombre accesible resume días activos y total; cada punto tiene su valor como título.
