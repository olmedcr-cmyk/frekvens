# DotLoader

Puntos que laten mientras algo piensa o carga: fila de tres (`row`) o rejilla 3×3 en onda diagonal (`grid`). Hereda el color del texto.

- **Props**: `variant` (`row` · `grid`), `label` (texto para lectores, "Pensando").
- Si la espera pasa de ~3 s, añade al lado qué está pasando ("Buscando huecos…").
