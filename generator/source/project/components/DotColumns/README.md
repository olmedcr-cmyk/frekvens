# DotColumns

Columnas de puntos apilados con la cima de cada una en `ink` y el pico señalado con una chincheta: la forma de una semana, sin ejes.

- **Props**: `data` (números o `{label, value}`), `rows` (5: puntos de la columna más alta), `max`, `active` (por defecto, el pico), `size`, `tone`, `label`.
- Redondea a puntos enteros: sirve para ver la forma, no para leer un valor. Si el valor importa, `ColumnChart`.
