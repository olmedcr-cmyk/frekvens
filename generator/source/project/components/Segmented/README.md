# Segmented

Selector en píldora `ink`: la opción elegida es una **pieza `paper` que viaja** de una opción a otra con `ease-spring` (380 ms) y se encoge un 3 % mientras pulsas. El `Home | 🔒` de Nothing. 2–4 opciones.

- **Props**: `options` (strings o `{value,label,icon,ariaLabel}`), `value`/`defaultValue`, `onChange(v)`, `label`.
- Teclado: flechas para cambiar (patrón radiogroup, un solo punto de tabulación).
- Navegación principal flotante al pie (centrada, `space-5` sobre el borde) o filtro de vista. Opciones solo-icono necesitan `ariaLabel`.
