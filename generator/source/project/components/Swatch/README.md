# Swatch

Un par de color en discos concéntricos: el fondo fuera y la marca dentro, con su nombre debajo.

- **Props**: `ground` y `mark` (nombre de un token, como `sol`, o cualquier color CSS), `label`, `note`, `size`.
- Para enseñar combinaciones de la paleta o dejar elegir un tema. Si se puede pulsar, envuélvelo tú en un control (`ChoiceCards`, `RadioGroup`).
