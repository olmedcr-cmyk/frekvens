# Timeline

Línea de tiempo vertical con el lenguaje de estados: hecho (disco), en curso (puntos), pendiente (aro), error. Sirve para despliegues, pedidos, historial de actividad (con `avatar`) y pasos de un proceso.

- **Props**: `items` (`[{title, text, time, state:'done'|'running'|'upcoming'|'error', avatar}]`), `label`.
