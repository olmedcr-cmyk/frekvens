# Stack

Primitiva de composición: apila hijos en columna o fila con un hueco de la escala de espacio. Existe para que una UI generada por un modelo no tenga que escribir CSS.

- **Props**: `direction` (`column` · `row`), `gap` (paso de espacio 1–9, por defecto 3), `align`, `justify`, `wrap`, `padding` (paso de espacio), `children`.
