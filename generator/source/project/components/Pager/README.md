# Pager

Carrusel horizontal con scroll-snap, botones redondos de anterior/siguiente y puntos de posición (el activo se alarga en píldora). Funciona con el dedo, con los botones y con ← →.

- **Props**: `children` (una diapositiva cada uno), `itemWidth` (`'85%'`, deja asomar la siguiente), `gap` (8), `label`.
- Para onboarding, tarjetas de rutina o galerías. Nunca autoavance.
