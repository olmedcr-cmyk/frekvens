# RadioGroup

Elección única con el lenguaje de estados: el aro vacío se llena hasta ser disco al elegirlo. Flechas para moverse dentro del grupo (patrón ARIA radiogroup).

- **Props**: `options` (strings o `{value, label, hint, disabled}`), `value`/`defaultValue`, `onChange(v)`, `label`, `direction` (`column` · `row`).
- 2–5 opciones con explicación. Sin explicación y con pocas opciones, `Segmented`.
