# Tooltip

Etiqueta flotante `ink` que explica un control sin texto. Aparece a los 400 ms al pasar el puntero o al enfocar, se cierra con Esc y nunca contiene acciones.

- **Props**: `content`, `side` (`top` · `bottom`), `delay` (400), `children` (un único elemento enfocable).
- En móvil no hay hover: lo esencial nunca vive solo en un tooltip.
