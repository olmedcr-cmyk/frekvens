# SplitBar

Reparto de un total: una barra de píldoras con leyenda (`bar`) o columnas altas con relleno redondeado (`columns`, el 70/30 de las referencias).

- **Props**: `segments` (`[{label, value, tone}]`), `variant` (`bar` · `columns`), `height` (220, columnas), `format(v)` (para la leyenda; por defecto %).
- 2–5 segmentos. El primero, el que importa.
