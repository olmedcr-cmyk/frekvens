# Scope

Osciloscopio: pantalla oscura con retícula de puntos (ejes centrales marcados) y una traza verde fósforo que corre en vivo. Para señales, audio, latidos, estado de un sensor.

- **Props**: `frequency` (ciclos en pantalla), `amplitude` (0–1), `noise`, `live` (true), `width`, `height`, `caption`, `label`.
- Con movimiento reducido la traza queda quieta.
