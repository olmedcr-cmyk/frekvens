# Stepper

Menos · número · más. Para cantidades pequeñas y enteras (series, plazas, minutos). El número entra rodando desde abajo al cambiar.

- **Props**: `value`/`defaultValue`, `onChange(n)`, `min` (0), `max` (99), `step` (1), `unit`, `label` (nombre del grupo; se usa en los botones: "Más series").
- En los límites el botón correspondiente se deshabilita. Para rangos grandes, `Slider` o `Dial`.
