# Scatter

Dispersión sobre una rejilla de puntos: cada observación es un disco con aro del color del fondo, y su tamaño puede ser un tercer dato. Ejes de un trazo.

- **Props**: `points` (`[{x, y, size, tone, label}]`), `xLabel`, `yLabel`, `width`, `height`, `label`.
- Al pasar el ratón cada punto dice su etiqueta y valores (`title`).
