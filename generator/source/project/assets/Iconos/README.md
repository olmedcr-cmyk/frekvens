# Iconos

Set propio de Frekvens: rejilla de 24 px, trazo 2 px, terminaciones rectas, transporte (`play` `pause` `stop` `rec`) relleno.

- Estos SVG van en tinta fija `#111111` (`ink` del tema claro) porque `<img>` no hereda color. Sobre fondos oscuros o de color, usa el componente `Frekvens.Icon` (hereda `currentColor`) en lugar del archivo.
- Tamaños: 24 en texto, 28 en `Keypad`, 32–48 en teclas grandes. Nunca por debajo de 20.
- Mismos nombres que `Frekvens.Icon.names`: play, pause, stop, rec, plus, minus, arrow-right, arrow-left, arrow-up-right, chevron-down, close, check, timer, power, lock, dots, home, drop, sun, flag, refresh, mic, arrow-up, copy, volume, volume-off, expand.
